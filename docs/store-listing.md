## 長い説明 (Full description) — 4000 文字以内

```
教科書の英単語、ノートに書き写すのは時間がかかる。
「英単語暗記」は、教科書の写真をカメラで撮るだけで英単語を読み取り、
自分だけの単語帳をつくれるアプリです。読み取った単語は活用形・発音記号・
日本語訳まで自動で揃うので、登録後すぐにクイズ形式で暗記学習を始められます。

■ 主な機能

【撮るだけで単語登録】
教科書を撮影するだけで、Google の高精度な OCR がページ内の英単語を抽出。
タップするだけで一括登録できます。手書き入力にも対応。

【活用形・発音記号を自動で取得】
登録した単語の品詞を自動判定し、動詞なら過去形・過去分詞・現在分詞・三単現、
名詞なら複数形、形容詞・副詞なら比較級・最上級まで生成します。発音記号と
音声 URL も自動取得。一発で「使える単語データ」が揃います。

【日本語訳も自動で】
Jisho.org / JMdict を利用して品詞に合った日本語訳を自動入力。和訳の入力ミスや
辞書を引く手間がなくなります。

【クイズで定着】
5つのモードから選んで反復練習：
・日本語 → 英語
・原形 → 過去形 / 過去分詞
・原形 → 現在分詞 (-ing 形)
・単数 → 複数
・原級 → 比較級 / 最上級

間違えた問題を優先出題するアルゴリズム搭載。間違えた直後に「練習する (3回)」で
すぐ反復することも可能です。

【出題範囲を自由に設定】
・登録した日付範囲で絞り込み
・品詞でフィルタ (動詞だけ / 名詞だけ等)
・特定の単語をピックアップして出題
・テスト範囲を保存して繰り返し利用
学校の単元別、定期テスト対策、受験対策など、目的に合わせた使い分けができます。

【SRS (間隔反復) で長期記憶へ】
正解した単語は徐々に出題間隔を伸ばし、忘れかけたタイミングで再出題する
スケジュール管理機能を搭載。短期記憶ではなく長期記憶に定着させます。

■ プライバシーへの配慮
・アカウント登録不要、メールアドレス・氏名等の入力は一切なし
・登録した単語データは端末内 (SQLite) にのみ保存。サーバー送信なし
・OCR 用の画像は Google Cloud Vision API に送信され、処理後は保持されません
・詳細はプライバシーポリシーをご確認ください

■ こんな方におすすめ
・中学・高校の英語授業の予習復習
・大学受験の単語対策
・TOEIC/TOEFL/英検 の語彙強化
・社会人の英語学び直し

教科書を撮って、活用形と発音つきで覚える。
紙の単語帳から進化した英単語学習アプリです。
```
